# 家系圖快速製作器 V6.2.0

本版取消掃描底圖、圖片上傳、本機圖片辨識及雲端 AI 判讀，保留文字轉家系圖與圖面轉文字。

## 圖面轉文字格式

- 精簡紀錄格式
- 社工敘述格式
- 社工口語紀錄模式

社工口語紀錄模式會將案主、家庭成員、婚姻／伴侶、親子、家庭互動、同住範圍及服務資源整合成連貫紀錄，產生後仍應由使用者人工核對及修訂。

## 使用方式

直接開啟 `index.html` 即可離線使用；上傳至 GitHub Pages 時也只需要 `index.html`。

## 個資提醒

專案資料預設只存於目前瀏覽器。JSON 專案檔仍可能含姓名、年齡、健康、暴力及家庭關係等敏感資料，請依機構規範妥善保存。
